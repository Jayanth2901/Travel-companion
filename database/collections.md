# MongoDB Collections

| Collection      | Description                          |
|-----------------|--------------------------------------|
| users           | Auth credentials and account info    |
| profiles        | Extended travel profiles             |
| trips           | Trip listings                        |
| tripmembers     | Trip join requests and membership    |
| chatrooms       | Direct and group chat rooms          |
| messages        | Chat messages                        |
| expenses        | Shared trip expenses                 |
| notifications   | In-app notifications                 |
| reviews         | User and trip reviews                |
| traveltwins     | AI preference embeddings per user    |
| recommendations | Cached AI recommendations            |
